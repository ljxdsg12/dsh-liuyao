# dsh-liuyao

**Six-yao (I Ching / Liuyao) divination plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).**

Xiantian bagua backdrop · Zhouyi opening verse · manual or simulated coin toss · najia charting ·
strictly sourced interpretation · one-hexagram-one-question follow-up dialog.

[中文说明](README.md) | English

---

## What it does

| Feature | Detail |
|---|---|
| Opening verse | Draws a passage from the *Zhouyi* classics (Xici / Shuogua / Xugua / hexagram & line texts), verbatim |
| Manual casting | Enter your exact time plus the six lines you tossed; every option spells out the matching **three-coin result** (`●○○　少阳 一背二字（静）`), so no prior knowledge is needed |
| Simulated toss | Throws three coins per line using a cryptographic RNG, one line at a time, confirmable before each throw |
| Charting | Main and changed hexagram, palace and shi/ying lines, six relatives, najia stems-branches, six gods, void branches, month-break, shensha, hidden spirits, nayin, seasonal strength, twelve stages, advancing/retreating transformations |
| Interpretation | Use-god / origin-god / foe-god analysis, generation-control combination-clash, six-god imagery, nayin imagery, hidden-spirit gain and loss, fan-yin / fu-yin, three-harmony, timing hints — **every statement cites the classical source it comes from** |
| Plain-language summary | The technical verdicts are followed by a jargon-free recap (what it means, what is blocking, what to do) |
| One hexagram, one question | A follow-up dialog marked **一卦一断**: answers only questions tied to *this* casting, generated by your own local model; out-of-scope questions are refused deterministically on the host side, without spending a model call |
| About panel | Version, licence, verified environment, a data-transparency statement, the disclaimer, the calendar self-test anchors (calendar output checked against an almanac), and how to reach the author for consulting or sponsorship |

## Install

Install from the tagged git reference (requires `git` on your machine):

```bash
dsh plugin --profile web add "github:ljxdsg12/dsh-liuyao#v0.1.0"
```

Or download `dsh-liuyao-0.1.0.tgz` from the release page and install that file:

```bash
dsh plugin --profile web add ./dsh-liuyao-0.1.0.tgz
```

Either way the installer registers the bundle in your profile automatically. **Restart DSH**, then
refresh the GUI — a **六爻** panel and sidebar icon appear.

> **Do not** install the release tarball directly by URL
> (`dsh plugin add "https://github.com/…/dsh-liuyao-0.1.0.tgz"`). DSH's installer currently writes a
> lockfile entry without an `integrity` field for remote tarballs, and pnpm then refuses with
> `ERR_PNPM_MISSING_TARBALL_INTEGRITY`. This is an installer/pnpm issue, not a packaging problem —
> the same tarball installs fine from a local path. See [KNOWN-ISSUE-install.md](KNOWN-ISSUE-install.md).
>
> Use a **branch or tag** reference (`#v0.1.0`, `#main`), never a commit SHA: pnpm resolves git refs
> with `git ls-remote`, which only advertises branches and tags.

## Configuration

Override in your profile's `cordis.patch.yml`:

```yaml
- id: liuyao
  name: dsh-liuyao
  config:
    enabled: true            # master switch: off = no tools, no data endpoints
    boardBackground: true    # bagua backdrop
    backgroundMode: auto     # auto | global | columns | off
    coinAnimation: true
    requireConfirmEachToss: true
    citationStrict: true     # only emit verdicts that have classical support
    followUpEnabled: true    # the 一卦一断 follow-up dialog
    maxFollowUps: 3
    followUpProvider: ""     # blank = use the session default model
    followUpModel: ""
```

To disable the whole plugin entirely: add `disabled: true` to that layer.

## What it never does

- **Zero npm dependencies** — the host half imports nothing but Node built-ins.
- **No network access, no filesystem writes, no credential reads.** In the community catalog's
  capability audit this plugin has an empty `capabilities` list: no red lines.
- The only outbound call is the optional follow-up question, which goes to **your own** configured
  model through DSH's `llm` service.

## Interpretation sources

Verdicts are restricted to these classical texts; anything without textual support is not asserted.

- 《增删卜易》(Zengshan Buyi) — use-god, origin/foe gods, month-day, void, month-break, advancing/retreating, back-generation/back-control, hidden spirits
- 《卜筮正宗》(Bushi Zhengzong) — najia assembly, shi/ying, six gods, hidden spirits
- 《黄金策》(Huangjin Ce) — use-god and shi/ying, combination and clash
- 《易冒》(Yimao) — eight palaces, meeting groups, six harms, nayin imagery
- 《易隐》(Yiyin, Cao Jiuxi) — hidden spirits, four stores, post horse, peach blossom, nayin
- 《火珠林》(Huozhu Lin) — the najia method, old yang / old yin
- 《周易应用经验学》(Qin Lunshi) — modern applied imagery and timing
- 《周易》经传 — opening verse, verbatim
